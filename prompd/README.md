# prompd

The short name for the Prompd command line. It runs [`@prompd/cli`](https://prompd.io), pinned to an exact version, and contains no other logic.

```bash
npx prompd install @scope/package@1.0.0
```

Every package is verified against its integrity record before anything is written to disk.

Requires Node.js 20 or later. Licensed under the Elastic License 2.0.
